# Nông Trại Vui Vẻ 3D

Demo game 3D thuê đất & nuôi trồng (quỹ đất mẫu 2.000m² ven Hà Nội). Trang tĩnh, không cần build — chạy bằng ES modules + three.js từ CDN.

- Chạy local: `npm start` rồi mở http://localhost:4173
- Test: `npm test`
- Pre-push hook: `git config core.hooksPath .githooks` (kiểm tra cú pháp + test trước khi push)
- Production: GitHub Pages từ nhánh `main`.
